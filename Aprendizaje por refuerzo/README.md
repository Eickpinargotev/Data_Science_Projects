# Proyectos de Aprendizaje por Refuerzo

Este repositorio contiene implementaciones de aprendizaje por refuerzo usando **Q-learning** en dos entornos de OpenAI Gym: **CartPole** y **Pendulum**.

## Archivos incluidos:

1. **balance_de_palanca.py**  
   Implementación de un agente que aprende a equilibrar un carrito con una barra (CartPole) usando Q-learning.  
   **Tutorial en video**: [Equilibrio de CartPole](https://youtu.be/wPTrz9r_qw4)

2. **pendulo.py**  
   Implementación de un agente que controla un péndulo para mantenerlo en posición vertical utilizando Q-learning con discretización del espacio de estados y acciones.  
   **Tutorial en video**: [Control de Péndulo](https://youtu.be/a0HAY2ZpC0A)
